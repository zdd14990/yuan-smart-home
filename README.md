# 隅安 YUAN — 智慧居家感知系统

> “让家的每一个角落，都懂你的呼吸。”

一个表面上是极简智能家居营销官网、随向下滚动逐渐异化并最终坠入第一视角恐怖片现场的交互式心理恐怖网页体验。

## 体验结构

- **第一幕（0%–20%）：阳光极简商业官网** — 暖白配色、玻璃拟态实时呼吸监测卡片与产品预约弹窗。
- **第二幕（20%–52%）：日常文案异化与恐怖谷评价** — 页面色温褪为冷调荧光灰绿，Bento 特性卡片渗出异常规则，住户头像随滚动无声叠化。
- **第三幕（52%–72%）：毫米波平面图雷达与接管细则** — 实时绘制房间平面剖面，未登记目标随滚动穿过走廊与门缝逼近屏幕前访客。
- **第四幕（72%–100%）：第一视角夜视恐怖长镜头与回滚污染** — 全屏粘性画布结合手电筒光锥、35mm/红外噪点、抽帧异动、死寂遮挡与贴脸终局；滑到底部后再返回顶部会触发污染态首屏。

## 运行方式

无需构建工具，直接用浏览器打开 `index.html`，或启动任意静态服务器：

```bash
python -m http.server 8080
```

建议开启页面右上角「声景」（基于 Web Audio API 实时程序化合成，无外部音频依赖）并全屏浏览。
